# OpenHarmony 书籍 —— 缺失章节骨架清单

> 本文档记录对照 OpenHarmony 官方架构后识别出的**当前目录缺失的重要内容**，以及本轮已建立的骨架章节与后续详细补全的优先级建议。
> 状态：**13 篇骨架已于 2026-07-07 全部补全正文**（详见各章；P0 核心 5 篇达 L2–L3，P2 系统基础服务 7 篇为扎实首通稿，可在后续"详细补全"阶段加深）。

## 一、缺口分析（对照 OpenHarmony 官方子系统）

本书已有 22 章，覆盖：学习 / 环境 / 工具 / 架构 / 源码 / Native / NAPI / samgr / HDF / 启动 / IPC+Binder / 图形 / 窗口 / 输入 / 媒体 / 分布式三件套（软总线·数据·硬件）/ 内核 / DFX / XTS / OTA。

对照官方架构，缺失的系统层重要主题如下（按重要度）：

| 缺失主题 | 重要度 | 原因 |
| --- | --- | --- |
| 安全子系统（HUKS / 设备认证 / 数据加密） | ★★★ | OpenHarmony 分布式安全的基石，目前完全空白 |
| 权限与访问控制（AccessToken / APL） | ★★★ | 应用权限模型缺失，与 Ability、包管理强相关 |
| 元能力 Ability 框架（FA/Stage/Want） | ★★★ | 应用模型核心，所有应用运行的基础，缺失 |
| 包管理子系统（HAP / App Pack） | ★★☆ | 应用包结构与安装流程，应用框架完整性所需 |
| 编译构建子系统（hb / GN / Ninja） | ★★☆ | 与"源码结构"衔接，实际动手编译所必需 |
| 分布式任务调度（流转 / 协同） | ★★☆ | 补全"分布式三件套"，实现跨设备 Ability 调用 |
| 电源管理子系统 | ★★☆ | 系统基础服务，与窗口/输入/启动联动 |
| 通知与公共事件 | ★★☆ | 应用与系统通信的重要手段 |
| 通信子系统（WLAN / 蓝牙 / NFC） | ★★☆ | 无线连接管理，分布式能力的承载 |
| 位置服务子系统 | ★★☆ | GNSS / 网络定位 / 地理围栏 |
| 全球化与国际化 | ★★☆ | 多语言、时区、格式化、资源分级 |
| 文件与存储子系统 | ★★☆ | 沙箱目录、媒体库、分布式文件 |
| 帐号与用户身份 | ★★☆ | 系统帐号、分布式帐号、IAM |

> 未纳入本轮（可后续考虑）：电话与移动网络、无障碍、壁纸/锁屏/主题、相机独立章（已含于媒体）、移植适配专题（已含于 HDF）。
